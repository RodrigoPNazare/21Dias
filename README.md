# Desafio 21 Dias - Desenvolvimento de Aplicações Web e Lógica Estruturada

Este repositório reúne uma suíte de pequenos softwares e algoritmos utilitários desenvolvidos em JavaScript (ES6+) e HTML5. O objetivo do projeto foi fixar conceitos essenciais da Ciência da Computação, evoluindo de forma prática desde a manipulação de variáveis básicas até estruturas de dados e regras de negócio complexas.

## 📁 Módulos e Estrutura do Projeto

### 🔹 Dia 1: Conhecendo o Usuário (`Dia1/ConhecendoUsuario/`)
* **Lógica:** Entrada e conversão de dados, operadores aritméticos básicos.
* **Aplicação:** Coleta dados de perfil (peso, altura, idade) para processar o ano de nascimento e calcular o Índice de Massa Corporal (IMC).

### 🔹 Dia 2: Tomada de Decisão e Operadores Lógicos (`Dia2/`)
* **Lógica:** Estruturas condicionais compostas (`if / else if / else`) e operadores lógicos (`&&` e `||`).
* **Aplicações:**
  * **Motorista:** Valida critérios de idade, posse de CNH e veículo para determinar a capacidade legal de condução.
  * **Jantar Especial:** Sistema de decisão para escolha de refeição baseado em fatores financeiros e operacionais.

### 🔹 Dia 3: Operadores e Utilitários (`Dia3/`)
* **Aplicações:** Desenvolvimento de minissistemas utilitários de rotina, incluindo uma Calculadora aritmética funcional e o módulo Posto de Gasolina para análise de consumo de combustível.

### 🔹 Dia 4: Estruturas de Repetição com Laço FOR (`Dia4/`)
* **Lógica:** Loops contadores, incrementos customizados (`+=5`), loops decrementais e laços aninhados (matrizes lógicas).
* **Aplicações:**
  * **Atividade 1:** Algoritmo de contagens progressivas dinâmicas e loops de salto de 5 em 5 (crescente e decrescente).
  * **Atividade 2 (Tabuada):** Gera de forma encadeada a tabuada completa de um número informado e dos seus dois sucessores aritméticos utilizando loops `for` sobrepostos.

### 🔹 Dia 5: Algoritmos Avançados de Análise Estatística (`Dia5/`)
* **Lógica:** Laços condicionais (`while` e `do-while`), acumuladores, contadores e busca de maior elemento.
* **Aplicações:**
  * **Caixa Eletrônico:** Emulação de terminal bancário com loop de transações de depósito/saque, controle de saldo e cálculo de médias.
  * **School Notas:** Processamento de dados educacionais com filtros estatísticos de desempenho segmentados por gênero.

### 🔹 Dia 7: Modularização e Funções (`Dia7/entregavelCalculadora/`)
* **Lógica:** Escopo de funções, passagem de parâmetros por valor, retorno de dados (`return`) e controle de fluxo com `switch/case`.
* **Aplicação:** Uma calculadora modularizada de alta performance. Além das 4 operações básicas, implementa um algoritmo iterativo customizado via loop `while` para processar potenciação (exponenciação aritmética).

### 🔹 Dia 8: Loops de Controle de Estado e Análise Temporal (`Dia8/`)
* **Lógica:** Loops estruturados `do-while` com flags de interrupção do usuário, processamento cronológico e simulação matemática progressiva.
* **Aplicações:**
  * **Conhecendo Usuário 2.0:** Módulo expandido de cadastro que calcula idades em frações de tempo (dias, semanas, meses), classifica níveis de IMC e processa uma linha do tempo histórica printando a idade que o usuário possuía em cada ano civil desde o seu nascimento.
  * **RH Previsão Salarial:** Algoritmo que simula uma projeção financeira de plano de carreira para os próximos 10 anos, aplicando reajustes salariais cumulativos e dobrando a taxa de aumento percentual a cada iteração anual.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Inicialização de ambiente client-side no navegador.
* **JavaScript (Vanilla ES6+):** Lógica orientada a funções, loops estruturados, controle de fluxo e manipulação de tipos.
